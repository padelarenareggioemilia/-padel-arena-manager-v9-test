AICS PADEL CHAMPIONSHIP V9.8.0 — VISTA PARTITE PERSONALIZZATA

CAPITANO E GIOCATORE
Possono scegliere tramite flag:
- solo le partite della propria squadra;
- tutte le partite della propria categoria;
- tutte le partite in assoluto.

La scelta viene ricordata per ogni account.

AMMINISTRATORE
Può scegliere:
- tutte le partite;
- una categoria;
- una singola squadra, selezionandola dall'elenco.

STAMPA E CONDIVISIONE
Tutti hanno:
- Stampa / Salva in PDF;
- Condividi questa vista.

Solo l'amministratore ha anche:
- Esporta in Excel.

Le partite restano divise per giornata.

INSTALLAZIONE
1. Esegui SUPABASE_V9_8_0_UPDATE.sql.
2. Su GitHub carica matches-view.html.
3. Sostituisci index.html, admin-control.html, captain.html e player.html.
4. Fai Commit changes.
5. Apri matches-view.html?v=980.
