# V9 Fase 1 — Core utenti e ruoli

- Amministratore: account obbligatorio, controllo completo.
- Collaboratore: account obbligatorio, tornei assegnati.
- Capitano: account obbligatorio; il link serve solo al primo collegamento con la squadra.
- Giocatore: account facoltativo; iscrizione pubblica via link sempre disponibile.

## Regola di sicurezza
La V9 deve usare un progetto Supabase di test distinto. Non inserire URL o chiavi della V8 operativa.
