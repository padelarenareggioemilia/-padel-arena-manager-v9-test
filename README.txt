PADEL ARENA MANAGER V9.2.0

FUNZIONI NUOVE
- Numero di gironi configurabile per Serie A, Serie B, Serie C e Coppa Italia.
- Assegnazione manuale delle squadre ai gironi.
- Assegnazione automatica geografica o bilanciata.
- Geolocalizzazione degli indirizzi dei club.
- Generazione automatica del calendario in base a giorno, orario e campo della squadra di casa.
- Girone di andata e ritorno configurabile.
- Ogni partita resta modificabile manualmente.
- Playoff, playout, semifinali e finali programmati all'Eden Padel Club di domenica dalle 10.
- Supercoppa tra vincitrice del campionato e vincitrice della Coppa Italia.
- Loghi ufficiali inseriti nelle pagine delle competizioni.

INSTALLAZIONE
1. In Supabase V9 Test esegui integralmente SUPABASE_V9_2_UPDATE.sql.
2. Su GitHub carica/sostituisci tutti i file e la cartella assets.
3. Fai Commit changes e attendi circa un minuto.
