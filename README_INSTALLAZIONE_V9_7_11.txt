AICS PADEL CHAMPIONSHIP V9.7.11 — IMPORTATORE INTELLIGENTE LOGHI

FUNZIONI
- Caricamento di un archivio ZIP.
- Supporto PNG, JPG, JPEG, WEBP, SVG e PDF.
- Ignora automaticamente __MACOSX e file ._.
- Elimina i duplicati identici tramite impronta SHA-256.
- Converte raster, SVG e prima pagina dei PDF in PNG.
- Ridimensiona immagini molto grandi.
- Abbina automaticamente il nome del file alle squadre.
- Mostra percentuale di affidabilità.
- Consente la scelta manuale della squadra.
- Anteprima del nuovo logo e del logo attuale.
- Importazione multipla con barra di avanzamento.
- Non sostituisce loghi già presenti senza autorizzazione esplicita.
- Funzione disponibile solo all'amministratore.

INSTALLAZIONE
Su GitHub:
1. Carica logo-import.html.
2. Sostituisci data-exchange.html.
3. Sostituisci index.html.
4. Fai Commit changes.
5. Apri logo-import.html?v=9711.

Non serve SQL.
Usa il bucket Supabase già esistente: team-logos.

NOTA
Le corrispondenze automatiche vanno comunque controllate prima di premere
“Importa selezionati”, soprattutto per file generici come “Logo quadrato”.
