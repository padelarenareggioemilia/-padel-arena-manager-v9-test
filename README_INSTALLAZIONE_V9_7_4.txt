AICS PADEL CHAMPIONSHIP V9.7.4

FUNZIONI
- Il capitano può nominare fino a 3 segretari.
- I segretari devono avere un account.
- Capitano e segretari possono compilare la formazione.
- Entrambe le squadre interessate vedono entrambe le formazioni fin dal primo inserimento.
- Ciascuna squadra può modificare soltanto la propria.
- A 120 minuti dall'inizio:
  non si possono più aggiungere o sostituire giocatori.
- Fino a 5 minuti prima:
  si possono cambiare ordine e combinazioni.
- A 5 minuti:
  distinta ufficiale bloccata.
- Tutte le modifiche vengono registrate.

VISIBILITÀ
Solo:
- amministratore;
- capitano squadra di casa;
- massimo 3 segretari squadra di casa;
- capitano squadra ospite;
- massimo 3 segretari squadra ospite.

INSTALLAZIONE
1. Esegui SUPABASE_V9_7_4_UPDATE.sql.
2. Su GitHub sostituisci:
   captain.html
   match-center.html
3. Carica:
   lineups.html
4. Fai Commit changes.
5. Apri:
   lineups.html?fixture=ID_PARTITA&v=974
